# ZIMO IPTV PLAYER

مشروع Android تجريبي باستخدام Kotlin وJetpack Compose.

## المزايا
- أقسام Live TV وMovies وSeries.
- إضافة قوائم M3U عبر رابط.
- إضافة حساب Xtream Codes (الخادم واسم المستخدم وكلمة المرور).
- ترتيب تلقائي حسب المجموعة ثم الاسم.
- جلب بيانات البث المباشر والأفلام والمسلسلات من Xtream API.
- إعداد GitHub Actions لبناء APK تجريبي.

## البناء
يتطلب Android Studio حديثاً وJDK 17 وAndroid SDK 35.
افتح المجلد في Android Studio وانتظر Gradle Sync ثم اختر Build > Build APK(s).

## الرفع اليدوي من الهاتف إلى GitHub
1. فك ضغط الملف.
2. افتح المستودع KAMALBOUARF/ZIMO-IPTV-.
3. اختر Add file ثم Upload files.
4. ارفع محتويات المجلد، وليس ملف ZIP وحده.
5. اضغط Commit changes.

## ملاحظات
- هذا مشغل تجريبي ولا يتضمن قنوات أو اشتراكات.
- استخدم قوائم وروابط تملك حق استخدامها.
- توافق Xtream يختلف حسب مزود الخدمة وقد يتطلب تعديلات.
- هذه النسخة لا تتضمن Firebase أو لوحة إدارة أو تفعيل Premium.
- واجهة التشغيل الفعلية المدمجة غير مكتملة في هذه النسخة؛ اختيار القناة يعرض رابطها لتجربة أولية.
